# Портфолио Анны Неволиной — версия с редактором

Сайт — статический, а контент редактируется через Decap CMS. Публикации и изображения хранятся в GitHub, а Tuqo автоматически публикует новую версию после изменения репозитория.

## Что редактируется
- все основные печатные тексты;
- тексты страниц;
- разделы портфолио;
- записи блога;
- фотографии публикаций и изображения.

## Схема
GitHub → Decap CMS → content/ и static/images/uploads → Tuqo Git CD → сайт.

## Важно
В `admin/config.yml` нужно заменить `REPLACE_WITH_DECAP_TURBO_SITE_ID` на Site ID из Decap Turbo, а домен — на адрес сайта Tuqo.
